# MASTER BUILD PROMPT: RALLYO Premium Luxury Padel App 3D Scroll Website

Build a premium luxury padel app 3D scroll website called RALLYO using vanilla HTML, CSS, and JavaScript.
The site must feel cinematic, romantic, couture-grade, and highly immersive — a padel app brand film translated into a website.
The hero section should be a scroll-driven cinematic reveal of a padel rally forming and transforming into a padel app.
Use GSAP and ScrollTrigger for all scroll-linked motion.
Use Lenis for smooth scrolling.
Use a single-file structure with index.html only.
